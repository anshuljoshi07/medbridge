# MedBridge build progress

Repo layout: `~/medbridge-app/` (git root, CLAUDE.md, implementation.md, docs/) → `medbridge/` (Serverpod workspace).

## Decisions (2026-11-16)
- **Test target: Chrome** for now (no full Xcode on this Mac, so no macOS/iOS builds). Camera / ML Kit / doc-scan services run behind interfaces with fake + "type it instead" implementations on web.
- **Docker:** the user is installing Docker Desktop. Server tests use Serverpod's embedded test Postgres (no Docker needed); `serverpod start` needs Docker.
- **med_core value types are hand-rolled immutable classes** (not freezed): zero codegen in the pure core keeps it identical on device, web and server. Spec A9.1 says freezed; same contract (immutable, value equality), no build_runner.
- **Built B4 before B3:** the reconciler is the safety-critical core and has no parser dependency.
- **Rule-table additions** (they only make results stricter, never weaker):
  - `SIG_UNSUPPORTED:{flag}`: a keep/change/start plan item whose sig is unsupported → Unknown/amber (A6.5). Evaluated after rows 1–2 (stop/hold still apply).
  - `COMBO_PARTIAL` is applied after rows 1–2, so stop/hold instructions win for a combo bottle that contains a stopped ingredient.
  - Multiple same-ingredient plan items: an exact product match wins; otherwise the most severe candidate result is used.
- **Question/flag rules:** dashboard flag = every red result; auto Question = red, Unknown, or a DDI hit. This gives B10's 4 Questions + 3 red flags.
- Placeholder rule rows carry `"test": true`; `class_groups.json` gained a `penicillins` group so class allergies work. Removed losartan/valsartan from the LASA placeholders (not a spec pair).
